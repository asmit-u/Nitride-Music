# Nitride Music

### Where sound meets simplicity.

I wanted a music player that felt premium, looked beautiful, and offered everything I needed — without unnecessary complexity. I couldn't find one that checked all the boxes, so I decided to build my own.

**Nitride Music** is a modern desktop music player built with JavaScript, designed around premium aesthetics, customization, lightweight performance, and a completely offline listening experience.

## ✦ Features

- **Premium Design** — A polished, modern interface inspired by premium desktop software.
- **Customizable Experience** — Personalize the player to match your taste.
- **Lightweight Performance** — Designed for minimal RAM and CPU usage.
- **100% Offline** — Enjoy your local music without requiring an internet connection.
- **Zero Bloatware** — No unnecessary features or background clutter.
- **Completely Free** — No subscriptions, hidden charges, or advertisements.
- **Desktop Only** — Built specifically for desktop computers.
